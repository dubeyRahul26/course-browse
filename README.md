---

## Implementation Notes

* The layout and component structure were built to closely match the provided Figma design.
* Responsive behavior was implemented for mobile (~375px) and desktop (~1440px).
* Hover states and basic interactions are included where appropriate.
* Course content uses local dummy data.
* Some responsive decisions were inferred where mobile designs were not provided.
